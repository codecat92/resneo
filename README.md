# ResNeo E-Learning – Frontend Demo

Situs statis (HTML, CSS, JavaScript murni) untuk contoh tampilan. Data hanya contoh dan disimpan di browser (localStorage), tanpa backend.

## Halaman
index (beranda dan kemajuan), ebook, kuis, video, login (admin), admin (dasbor)

## Jalankan lokal
Buka `index.html`, atau jalankan `npx serve .`

## Deploy ke Vercel
1. Buat repo GitHub, lalu `git init && git add . && git commit -m "init" && git push`
2. Di vercel.com klik Add New > Project, pilih repo ini
3. Framework Preset: Other. Kosongkan Build Command dan Output Directory, lalu Deploy

## Mengganti gambar
Ilustrasi ada di `assets/` (SVG). Ganti dengan foto asli dengan nama file yang sama atau ubah atribut `src`.
